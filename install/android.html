What you are installing

EcoTrek records walks, hikes and bike rides: GPS route and distance, the trails near you, the weather you would be walking in, and the points and trees you earn along the way.

Your walks, points and settings are stored on this phone. There is no account to create and nothing is uploaded to us. The app has no ads and no trackers; it reaches the internet only for trail search, weather and — if you add your own key — the assistant's optional AI answers. The privacy policy lists every request it makes, in the same plain language as this page.

Installing it

  1. Tap “Download EcoTrek”. Your browser saves EcoTrek.apk to Downloads. Nothing installs yet.
  2. Open the download. Tap the download notification, or open Files → Downloads → EcoTrek.apk.
  3. Allow this one install. Android may say your phone is not allowed to install unknown apps from this source. Tap Settings, turn on Allow from this source, then go back. It is per-app, and you can switch it off again afterwards.
  4. Tap Install, then Open. EcoTrek appears in your app drawer like any other app.

About the Play Protect message

Android may show a panel reading “Unsafe app blocked” or “Play Protect doesn’t recognise this app”, with buttons like More and Don’t install. It appears for any app installed outside the Play Store, because Play Protect only knows the apps it has seen there. Nothing was found in the file — it just has not met this one before.

  1. Tap More — shown as More details on some phones, or as a small ⋮ menu.
  2. Tap Install — shown as Install anyway or OK on some phones.
  3. The install continues exactly as it would from the Play Store. Play Protect stays on; you have only told it “yes” for this file, once.

On Samsung and Pixel: More details → Install anyway. On Xiaomi/Redmi: Install anyway, then a second confirmation may ask to disable “Scan device”. You do not have to turn off Play Protect — the per-app confirmation is enough, and it only applies to this install.

The same panel appears for F-Droid, Amazon, a company intranet, or a file a colleague sent you. If you would rather not take it on faith, the next section checks the file itself in about ten seconds.

Check the file you downloaded

Every Android app is signed before it can be installed. EcoTrek is signed with the same certificate for every release, using all three current signature schemes:

  • v1 (JAR signing) — a per-file signature, understood by every Android version.
  • v2 (APK Signature Scheme v2) — covers the whole file, so entries cannot be added, removed or edited after signing.
  • v3 — the same protection with the ability to rotate keys in the future.

Updating, uninstalling, keeping your data

Will installing this version erase my progress?

No. Every EcoTrek build is signed with the same certificate, so Android treats it as the same app and upgrades it in place. Walks, badges and settings stay.

How do I update later?

Download the new file from this page and install it over the old one — no uninstall step. The version number in the table above tells you which build you have.

How do I uninstall it?

Long-press the EcoTrek icon → App info → Uninstall. That also removes the app’s local data, including any AI key you pasted in.

Why is the file small?

It is a small native shell around the same app you can open in a browser, shipped offline. One codebase serves Android, iPhone and desktop, and the download stays light.

Is there a Play Store version?

Not yet. Direct download is the distribution path for this build. If a Play Store listing is published later, this page will link to it.

Prefer not to install anything?

The full app also runs in your browser: open EcoTrek in the browser. You can add it to your home screen later without downloading a file.
