There is no App Store download for EcoTrek yet. The Home Screen version below is the full app, and it updates itself the moment we ship a new version — nothing to re-install.

Add EcoTrek to your Home Screen

  1. Open Safari and go to this site (not Chrome or Firefox — only Safari can add a Home Screen app on iOS).
  2. Tap the Share button — the square with an arrow pointing up, in the toolbar.
  3. Scroll down and tap “Add to Home Screen”, then Add.
  4. Launch EcoTrek from the new icon. It opens full screen, keeps its own storage, and is where you record walks.
Allow location when Safari asks. EcoTrek only asks while you start a recording, and only precise location makes a route accurate. Choose Allow While Using the App.

Why not an App Store download?

An iOS build needs an Apple Developer account and App Review, which is a separate track from this Android + web release. Until that store listing exists, we will not ship an unsigned IPA from this page: a file like that cannot be installed on a normal iPhone, and pretending otherwise wastes your time.

Questions

Do I lose my data by using the Home Screen version?

No. Safari keeps the app’s storage per site, and the Home Screen app uses the same storage. Your walks, points and settings stay on the device.

How do I remove it?

Long-press the icon → Remove Bookmark (or Delete Bookmark). Clearing Safari’s website data for this site also removes anything EcoTrek stored.

Can I use it offline?

The app opens offline and your recorded activities are kept locally. Trail search and weather need a connection because they come from live services.

I have an Android phone — which page do I need?

Use the Android install guide: it covers the signed APK and the Play Protect prompt.
