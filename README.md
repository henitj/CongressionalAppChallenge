# EcoTrek
The Concept: An interactive map and gamified platform built to help maintain Austin’s parks, creeks, and greenbelts. Users would complete a biking or hiking trail in Austin and publish their results which would then be used to plant a few trees for every trail completed by the user.

Austin Fit: With over 300 parks and growing green spaces, this app connects to city-wide initiatives and partners like the Austin Parks Foundation, turning park maintenance into a rewarding, community-driven event.
