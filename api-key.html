API key · optional

An optional AI key.

The assistant answers from the phone itself — no account, no key, no connection needed. If you want livelier answers, you can add a key from an AI provider. This page shows where to get one and where it goes.

Optional. Trails, weather, recording, points and badges all work without a key. Add one only if you want the assistant rephrasing its answers through a language model.

Where it goes in the app

  1. Open EcoTrek — in the Android app, in your iPhone Home Screen app, or in the browser.
  2. Go to Trail assistant in the bottom navigation.
  3. Tap AI settings (the sliders icon in the top right of that screen).
  4. Pick your provider — Groq, OpenAI, OpenRouter or your own server — then paste the key into the field labelled “Paste your API key”.
  5. Tap Save & test. If the screen answers “Connected — AI answers are on.” you are done. If not, jump to troubleshooting below.

To switch it off again, open the same sheet and tap Remove key. The assistant goes straight back to its on-device answers.

Pick a provider and copy the key

Keys come from the provider’s own site — none is issued or stored here. Open a card, create a key, copy it. The app already fills in the address and model for the three presets, so the key is the only thing you paste.

Your own server

Any OpenAI-compatible endpoint works, including a model you host yourself (Ollama, LM Studio, vLLM, a company gateway).

Base URL

Model

Key

EcoTrek calls {baseUrl}/chat/completions. Base URLs must use https:// so the key is never sent in clear text.

Where the key goes, and where it does not

QuestionAnswer
Where is it stored?In EcoTrek’s private storage on your device, next to your walks. It is not part of any account and it is not uploaded to us.
Who receives it?Only the provider you selected, sent as the Authorization: Bearer … header on requests to that provider’s own address — over HTTPS.
Do we see it?No. EcoTrek has no server that your key passes through, and no analytics that could capture it.
Is it in a backup or a screenshot?It lives in the app’s local storage, so a device backup that includes app data would include it. Treat it like a password and avoid sharing screenshots of the settings sheet.
What if it leaks?Sign in to the provider and revoke the key. A revoked key simply stops working; nothing in EcoTrek breaks — the assistant falls back to on-device answers.

The full details are in the privacy policy, including the exact list of network requests the app makes.

If the test does not pass

“Could not reach the model.”

Check the key, the provider and your connection — in that order. Copy the key again from the provider’s page: keys are long, and a missing character is the most common cause. Also confirm the base URL matches the provider (the provider cards above show the exact values the app pre-fills).

401 / “Not connected” straight away.

The key was rejected: it may have been revoked, or it belongs to a different provider than the one selected. Create a fresh key and paste it again.

429 or “rate limit”.

Free tiers have per-minute limits. Wait a minute and try again, or switch to a different model in the same sheet.

The test passes but answers are still the plain ones.

The assistant always answers from the device first, then upgrades the answer when the model responds. If a request fails, you keep the on-device answer — that is deliberate. Slow connections can also make the model reply after you have already read the first answer.

Can I type the key on a computer and move it to the phone?

Yes, but not by copying files: open the provider’s page on the phone and paste the key there, or use the provider’s own key-sharing flow. Avoid emailing keys to yourself.

Something else? ecotrek.support@gmail.com — never send the key itself, just the message the app showed.
